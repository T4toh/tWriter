Cómo usar git con esta carpeta

Git te da snapshots automáticos, historial completo y backup gratis en GitHub. Es opcional — tWriter funciona igual sin git, pero versionar tu novela suma tranquilidad.

  1. Abrí una terminal en la carpeta de la novela. 
    cd "{{ root() }}"
  2. Iniciá el repo y hacé el primer commit. 
    git init
git add -A
git commit -m "inicio"
  3. Creá un repo privado en GitHub.

    Ingresá a github.com/new y poné un nombre. Dejalo en privado — tu novela no es para el mundo todavía.

  4. Conectá el repo local con GitHub y subí los archivos. 
    git remote add origin git@github.com:<usuario>/<repo>.git
git branch -M main
git push -u origin main

Requisitos: tener git instalado y una clave SSH cargada en GitHub. Si no la tenés, generala con ssh-keygen -t ed25519 y pegá ~/.ssh/id_ed25519.pub en Settings → SSH keys de GitHub.

Cuando cerres este diálogo, tWriter va a re-chequear la carpeta. Si ya corriste git init, el badge cambia a Git automáticamente y aparecen los controles de sync.
